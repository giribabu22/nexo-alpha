# create-nexo-app

The official scaffolding tool for **Nexo** applications.

## Quick Start

```bash
# Interactive / Default fullstack React + Nexo template
npx create-nexo-app my-app

# Standalone backend API service
npx create-nexo-app my-service --template backend-api

# Minimal single-file setup
npx create-nexo-app quick-start --template minimal
```

## Options

- `-t, --template <name>`: Template choice (`fullstack-react`, `backend-api`, `minimal`). Default is `fullstack-react`.
- `-h, --help`: Display help and available options.
